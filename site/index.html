Contract first

Before the action runs, write what “done” means: subject, postconditions, forbidden side effects, retry window.

Independent readback

A read-only credential the agent doesn't hold. Writes are refused with 403, so Verify can't fix what it checks.

Append-only evidence

Every claim, readback and verdict goes into a SQLite ledger where each event hashes the one before.

Five verdicts. Only one counts.

VerdictMeaning
passEvery postcondition observed in the system of record
failA postcondition observed false, or a forbidden side effect seen
inapplicablePreconditions weren't met; the action should never have run
not_observedThe record is absent after the observe window
blockedReadback impossible (auth, outage, rate limit); retried with backoff, then fails closed
